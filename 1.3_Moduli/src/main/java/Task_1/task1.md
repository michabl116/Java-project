# Algoritmi 1000 iän arvon tuottamiseksi

- Kerää tiedot opiskelijoiden ikäjakaumasta.
- Esitä jakauma listana pareja, missä  on tietty ikä ja on opiskelijoiden määrä kyseisessä iässä.
- Laske yhteen kaikki esiintymiskerrat saadaksesi opiskelijoiden kokonaismäärän.
- Laske kunkin iän suhteellinen todennäköisyys jakamalla sen esiintymiskerrat kokonaismäärällä.
- Käytä painotettua satunnaisotantaa valitaksesi iät niiden todennäköisyyksien perusteella.
- Toista prosessi 1000 kertaa saadaksesi lopullisen otoksen.
