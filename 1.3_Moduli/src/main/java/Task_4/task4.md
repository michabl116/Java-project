# Kokeiden pistemäärät: 
- Kokeiden, kuten ACT-testin, pistemäärät noudattavat normaalijakaumaa, jonka keskiarvo on 21 ja keskihajonta noin 5.
# NFL-pelaajien eläkeikä: 
- NFL-pelaajien eläkeiän keskiarvo noudattaa normaalijakaumaa, jonka keskiarvo on 33 vuotta ja keskihajonta 2 vuotta.
# Verenpaine:
- Miesten diastolinen verenpaine noudattaa normaalijakaumaa, jonka keskiarvo on noin 80 ja keskihajonta 20.
